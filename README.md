# Toco Cafe Experience

This is a standard React application built with Vite. It uses JavaScript (`.js` and `.jsx`) and plain CSS only—there is no TypeScript, Tailwind, Sass, or other CSS framework.

Build a modern cafe website for a cafe called "Toco Speciality" inspired by the visual design and layout of https://cocksandcows.dk/.

I've attached the logo image of the cafe for your usage.

Recreate the overall design language: bold oversized typography, large full-width imagery, strong visual hierarchy, generous spacing, modern branding, editorial-style sections

Do not copy the original restaurant's content, branding, logo, text, images, or exact assets. Use your own creative texts and phrases.
Use #D7CEBF and #31312F as these are the colors used in the attached logo. 

The website should be fully responsive for desktop, tablet, and mobile.

Include:

Full-screen/large hero section

Navigation/header

Footer

Use high-quality food photography, bold typography, smooth scrolling, subtle animations, hover effects, and a polished premium restaurant aesthetic.

Make the implementation production-ready and ensure spacing, typography, image proportions, responsiveness, and interactions are carefully refined.

I've attached a series of images showing how my ideal cocksandcows.dk website looks. I've named the images in order, with numbers from 1 -11, 1 being the top of the website, 11 being the bottom of the website, so that you're fully aware of how it looks. Use the design shown in those images.

For now, just build the Home page. We'll build the other pages once we handle the Home page.
