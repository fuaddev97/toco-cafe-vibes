# Toco Color and Mood Refinement

## Goal
Warm and brighten the existing home page while preserving its layout, typography, content, imagery, spacing, interactions, and responsive behavior.

## Changes
- Keep `#D7CEBF` cream and `#31312F` charcoal as the dominant brand colors.
- Add subtle light, sand, coffee, and terracotta semantic color tokens for controlled surface variation and accents.
- Replace the hero’s uniform dark wash with a lighter left-to-right warm charcoal overlay so the café photography reads naturally while text remains clear.
- Keep hero typography unchanged, using warm off-white text and the existing cream/charcoal button treatment.
- Rebalance section backgrounds into a warm rhythm of cream, light warm white, sand, and occasional charcoal.
- Use muted terracotta only for small labels, icons, fine details, and restrained hover feedback.

## Validation
- Confirm the page’s structure and wording remain unchanged.
- Check desktop and mobile rendering for text contrast, image clarity, color balance, and working navigation.
