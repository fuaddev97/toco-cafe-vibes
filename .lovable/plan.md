# Toco Speciality Home Page

## Goal
Create a polished, responsive cafe home page that uses Toco’s logo, warm neutral palette, bold editorial typography, full-width food photography, and strong section-to-section contrast inspired by the supplied references without copying their content.

## What I’ll build
- A large immersive opening section with the Toco mark, concise original positioning, primary reservation/menu actions, and premium cafe imagery.
- A refined navigation bar with desktop links and a functional mobile menu.
- Editorial full-width sections for the Toco story, signature coffee and food, cafe atmosphere, and current highlights.
- Large image-led feature blocks with alternating compositions, oversized type, restrained motion, and tactile hover states.
- A clear visit/contact section and compact branded footer.
- Fully responsive layouts for desktop, tablet, and mobile, including accessible controls and reduced-motion support.

## Visual direction
- Use `#D7CEBF` as the warm stone base and `#31312F` as the charcoal anchor, translated into semantic theme tokens.
- Pair condensed, high-impact display type with a clean modern body face.
- Keep corners restrained and layouts spacious, with sharp editorial crops and strong image proportions.
- Use original cafe-focused copy and newly generated coffee, pastry, brunch, and interior photography.
- Use the uploaded Toco logo in the page and create a matching favicon from it.

## Technical details
- Replace the placeholder home screen while preserving the existing TanStack app structure.
- Store the uploaded logo through the project asset flow and import it into the page.
- Generate and locally import the new photography required by the design.
- Add route-specific title, description, Open Graph, and social card metadata.
- Validate the finished page at desktop and mobile sizes, checking navigation, image loading, spacing, overflow, and interactions.
